# Frontapp API Endpoint Reference

This document used to be a hand-maintained inventory of Front's REST endpoints

- implementation status. That inventory was imported from an earlier single-file MCP
  prototype and drifted from this repo's actual coverage as verticals shipped.

The authoritative sources are now generated from the spec or the code, and cannot drift:

- **Per-endpoint shape** (response type, list-shape, mutation flag, generated module
  name, helper / domain status): [`docs/api-facts.yaml`](api-facts.yaml). Generated by
  `scripts/generate_api_facts.py`, validated in CI by `uv run poe facts-check`.
  Pre-computed reverse indexes in `summary.*` answer the most common factual questions
  in one grep.
- **Vendored OpenAPI spec**: [`docs/frontapp-openapi.yaml`](frontapp-openapi.yaml).
  Refreshed by `uv run python scripts/vendor_spec.py`.
- **High-level coverage table**: top-level
  [README](https://github.com/dougborg/frontapp-openapi-client/blob/main/README.md#api-coverage)
  shows which verticals have hand-written ergonomic helpers and MCP tools.
- **Generated Python client**: every endpoint Front documents is reachable via
  `from frontapp_public_api_client.api.<tag> import <operation>`. Browse
  [`frontapp_public_api_client/api/`](https://github.com/dougborg/frontapp-openapi-client/tree/main/frontapp_public_api_client/api)
  for the full surface (139 paths, 233 operations as of the last regen).

To answer "is endpoint X implemented in this repo?", consult `docs/api-facts.yaml` first
— it's machine-derived and CI-validated, so it cannot lie about the current state.
